# Audit Records

This branch retains bounded assurance results tied to repository revisions,
controlled artifacts, workflows, or other declared validation frames.

Current groups are:

- `document-audits/` — assurance results for controlled documents.
- `workflow-audits/` — assurance results for repository workflows.

# Project Records

This directory is the default durable convergence location for project-local
Records. It is an integration boundary, not a Record taxonomy and not the
semantic owner of its children.

Current branches are:

- `Work/` — closed Work history and execution provenance;
- `Research/` — retained investigation evidence;
- `Decisions/` — durable decision provenance;
- `Fault/` — retained fault evidence and causal analysis;
- `Audits/` — bounded assurance evidence;
- `User/` — user-originated project-local provenance.

Each child README declares its own admission and retrieval contract.

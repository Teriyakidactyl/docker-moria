# User-Originated Records

Store user-originated information here only when preserving its provenance is
useful after the immediate interaction and it does not belong to a stronger
current-authority or specialized Record location.

Do not use this branch as a generic notes bucket or substitute for Work,
Research, decisions, Fault Records, or current guidance.

# Repair Moria Saved target

## Outcome

Published a docker-moria image whose pre-start persistence hook recreates
`/world/Saved` when `/app/Moria/Saved` is already the expected symlink but
its target is absent.

## Acceptance conditions

- The hook materializes the Saved target before accepting the expected symlink
  as converged.
- A regression test reproduces a dangling expected Saved symlink and proves the
  target is recreated and writable.
- Existing persistence migration, configuration idempotence, vcrun reuse, and
  PE subsystem tests remain green.
- The multi-architecture image build passes for the exact change and the
  publish run completes successfully.

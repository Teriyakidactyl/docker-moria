# Work Records

Move Work here when active attention ends. The retained artifact keeps its
durable identity and immutable `YYMMDD.##` creation locator, records one
disposition and close date, and no longer participates in priority scheduling.

Record filenames use:

```text
YYMMDD.## Concise title.md
```

These files are historical/provenance records, not current product authority.

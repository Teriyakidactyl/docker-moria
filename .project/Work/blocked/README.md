# Blocked Work

Place Work here only after execution has been admitted and a specific condition
prevents progress. Record the blocker, relevant evidence, and next check or
action in the Work file.

When the blocker clears, move the Work back to `../active/` when execution can
resume. Draft Work with ordinary unsatisfied prerequisites remains in
`../drafts/`.

Closed Work moves to `../../Records/Work/`.

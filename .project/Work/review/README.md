# Work In Review

Place Work here when execution is materially complete but a declared review or
validation condition still determines acceptance.

If review requires more execution, move the Work to `../active/`. If review is
blocked, move it to `../blocked/`. When acceptance is established or attention
intentionally ends, close the Work into `../../Records/Work/`.

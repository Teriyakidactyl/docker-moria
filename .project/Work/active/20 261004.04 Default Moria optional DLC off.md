# Default Moria optional DLC off

## Outcome

Publish docker-moria with optional DLC disabled by default while retaining an
explicit opt-in API for expansion worlds.

## Acceptance conditions

- `WORLD_OPTIONAL_DLC` defaults to empty in the image and supplied Compose file.
- The pre-start hook renders an empty `OptionalDLC.Array` when the variable is
  unset.
- Tests prove both the empty default and explicit DLC opt-in.
- README guidance explains that expansion-enabled worlds require expansion
  ownership and cannot be made base-game compatible merely by changing this
  creation setting later.
- Exact PR-head quality and multi-architecture build gates pass before merge.

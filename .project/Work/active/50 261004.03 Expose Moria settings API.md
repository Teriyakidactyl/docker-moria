# Expose Moria settings API

## Outcome

Publish docker-moria with a documented environment-variable API for every
currently known `MoriaServerConfig.ini` setting while preserving unknown
future native settings.

## Acceptance conditions

- Every currently known INI setting maps to a documented environment variable
  with a container default and native section/key.
- Source comments link the upstream dedicated-server/settings material and DLC
  upgrade guidance used to establish the schema.
- `envsubst` renders only an explicit allow-listed desired-state fragment.
- Reconciliation updates only API-owned keys and does not replace the
  persistent file when values are already converged.
- Tests cover all known mapped keys, exact dotted-key matching, unknown-setting
  preservation, no-op inode stability, and the existing Saved-target repair.
- The README exposes the complete API and links the official settings sources.
- The exact PR head passes quality and multi-architecture build validation, then
  the merged production run publishes the image.
